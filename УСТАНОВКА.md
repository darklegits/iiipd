# Как установить и проверить «Погодный оракул»

Два способа: готовый EXE (ничего ставить не нужно) и запуск из исходников.

---

## Способ 1. Готовое приложение (Windows 10/11, x64)

1. Откройте вкладку **Releases** репозитория и скачайте
   `WeatherOracle-portable.zip` (последний релиз).
2. Распакуйте архив в любую папку — например, `C:\WeatherOracle`.
   Важно распаковать **всю папку**, а не запускать файл из архива.
3. Запустите `WeatherOracle.exe`.
4. Windows может показать «Windows защитила ваш компьютер» — нажмите
   «Подробнее» → «Выполнить в любом случае» (файл не подписан сертификатом).
5. Первый запуск занимает 15–60 секунд: приложение распаковывается,
   копирует данные и загружает модели. Затем откроется отдельное окно
   без адресной строки.
6. Закрытие окна останавливает локальный сервер.

Если браузера Chrome/Edge нет, приложение откроется в системном браузере.

### Что проверить

| Раздел | Что смотреть |
|---|---|
| **Прогноз** | живые данные, карточки по дням, график, переключение 7/10/14, °C/°F, CSV |
| **Спорт** | индекс комфорта, 12 видов активности, экипировка, предупреждения, галерея направлений |
| **Сравнение** | MAE/RMSE, таблица моделей, график «прогноз vs факт» |
| **Модели** | веса ансамбля, метрики по горизонтам |
| **Методика** | отсутствие утечек, сплиты train/validation/test |
| **Личный кабинет** (кнопка-аватар) | имя, любимые виды, уровень, цель, план на неделю, сохранение профиля |
| **Уведомления** | включить, выбрать время, «Проверить уведомление» |
| **Музыка** | динамик в шапке + шеврон: громкость 0–100 %, по умолчанию 60 % |
| **Города** | 65 городов по алфавиту; у городов без ML стоит метка «Яндекс» |
| **Офлайн** | отключите интернет и перезагрузите страницу — откроется последний прогноз |

## Способ 2. Запуск из исходников

Нужен Python 3.13 (подойдёт 3.11+).

```powershell
git clone https://github.com/darklegits/iiipd.git
cd iiipd
.\setup.cmd      # установит зависимости и локальную папку .vendor
.\run.cmd        # запустит сервер на http://127.0.0.1:8000
```

Дальше откройте <http://127.0.0.1:8000> — это тот же интерфейс.

Данные и модели уже лежат в репозитории (`data/`, `artifacts/`), поэтому
обучать ничего не нужно. Если Open-Meteo недоступен, приложение
переключается на Яндекс.Погоду — источник подписан в интерфейсе.

Пересобрать EXE самостоятельно:

```powershell
.\build.cmd
```

Результат: `dist\WeatherOracle\WeatherOracle.exe` (запускать из папки
целиком, вместе с `_internal`).

## Если что-то не работает

- **«Нет свежих данных...»** — проверьте интернет и нажмите «Повторить»;
  страницы бэктеста остаются доступными.
- **Антивирус ругается на EXE** — файл не подписан, это ожидаемо;
  добавьте в исключения или запустите из исходников.
- **Первый запуск долгий** — так и должно быть: распаковка + загрузка моделей.
- **Логи** — в папке `userdata\oracle.log` рядом с EXE.
