ПОГОДНЫЙ ОРАКУЛ — Windows-приложение
====================================

ЗАПУСК
------
Двойной щелчок по WeatherOracle.exe (файл рядом с этим текстом).
Первый запуск 15–60 секунд.

ЗАПУСКАТЬ НУЖНО ТОЛЬКО ЭТОТ ФАЙЛ
--------------------------------
Папка dist\WeatherOracle — единственная готовая сборка.
В папке build\ лежат промежуточные файлы PyInstaller; похожий на вид
WeatherOracle.exe внутри build\ НЕ ЗАПУСКАЕТСЯ (там нет _internal),
и Windows покажет ошибку «Failed to load Python DLL».

ИСТОЧНИКИ
---------
1. Open-Meteo — ML-ансамбль и история.
2. Если Open-Meteo недоступен, автоматически используется публичная
   страница Яндекс.Погоды на 14 дней; в интерфейсе указан источник.
3. Если недоступны оба — сообщение и кнопка «Повторить», без выдуманных данных.

ПЕРЕНОС НА ФЛЕШКУ
-----------------
Копируйте всю папку WeatherOracle целиком, включая _internal и userdata.
Запускайте WeatherOracle.exe с флешки; путь к данным определяется от EXE.

ОБНОВЛЕНИЕ
----------
Прогноз обновляется при запуске и каждые 15 минут.
История сохраняется в userdata/data.

ЕСЛИ WINDOWS ПРЕДУПРЕЖДАЕТ
--------------------------
Файл не подписан. Нажмите «Подробнее» → «Выполнить в любом случае».

ОСТАНОВКА
---------
Закройте окно приложения. Сервер завершится автоматически.
