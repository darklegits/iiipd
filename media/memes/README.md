# Мемы героев

Сюда можно класть звуки, которые проигрываются при открытии карточки героя.

Имя файла — ключ героя из `data/heroes.json`, например:

```
media/memes/shadow_shaman.mp3
media/memes/pudge.mp3
media/memes/invoker.mp3
```

Если файла нет — играет короткий синтезированный «позывной» героя (генерируется в браузере, без файлов).

Настройки в приложении: шестерёнка → «Мемы героев» (вкл/выкл) и «Громкость мемов».
